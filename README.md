# 📸 Instagram Clone - Real-Time Social Media Platform

A high-performance, full-stack Instagram clone built with modern web technologies, featuring real-time messaging, user activity tracking, posts creation, dynamic interactions, and fully integrated high-fidelity WebRTC voice/video calls.

---

## 🌟 Key Features

- **📸 Interactive Feeds & Media**: Create, like, dislike, comment on, and bookmark posts. Real-time notifications keep users updated on interaction status instantly.
- **💬 Real-Time Direct Messaging**: One-on-one live chat powered by **Socket.io** with instant online/offline presence updates.
- **📞 WebRTC High-Fidelity Audio/Video Calls**: Start a voice or video call directly from the chat header. Built natively using `RTCPeerConnection` for crystal-clear audio and video streams with responsive picture-in-picture window overlay.
- **👥 Social & Follow Systems**: Seamless follow/unfollow capabilities to discover and grow user connections.
- **⚙️ Dynamic User Profiles**: Customizable profiles allowing users to update their bio, avatar image uploads via Cloudinary integration, and list post portfolios.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: React.js & Vite (Lightning-fast builds)
- **State Management**: Redux Toolkit & Redux Persist
- **Styling**: Tailwind CSS & Lucide Icons
- **Real-Time Communication**: Socket.io-client & native WebRTC API

### Backend
- **Runtime**: Node.js & Express.js
- **Database**: MongoDB & Mongoose (Schema models for Users, Conversations, Messages, Comments, and Posts)
- **Asset Storage**: Cloudinary (Image uploads) & Multer (Multi-part file parsing)
- **Security & Session**: JWT (JSON Web Tokens), bcryptjs (password hashing), and cookie-parser (Secure cross-origin cookies)

## 🚀 Setup & Installation

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) and [MongoDB](https://www.mongodb.com/) installed.

### 1. Clone the Repository
```bash
git clone https://github.com/DIPANSHU66/dipanshu-instagram.git
cd dipanshu-instagram
```

### 2. Backend Configuration
Navigate to the `backend` folder and install dependencies:
```bash
cd backend
npm install
```

Create a `.env` file in the `backend` directory and add your credentials:
```env
PORT=8000
MONGO_URL=your_mongodb_connection_string
SECRET_KEY=your_jwt_secret_key
CLOUD_NAME=your_cloudinary_cloud_name
API_KEY=your_cloudinary_api_key
API_SECRET=your_cloudinary_api_secret
URL=http://localhost:5173
```

Start the backend development server:
```bash
npm run dev
```

### 3. Frontend Configuration
Navigate to the `frontend` folder and install dependencies:
```bash
cd ../frontend
npm install
```

Create a `.env` file in the `frontend` directory:
```env
VITE_API_URL=http://localhost:8000/api/v1
```

Start the frontend Vite development server:
```bash
npm run dev
```

## 📦 Deployment Note
For cross-origin production deployment:
- Auth cookies are configured with `sameSite: "none"` and `secure: true` to prevent CORS authentication issues.
- Ensure CORS options in `backend/index.js` allow requests from your deployed frontend domain.
